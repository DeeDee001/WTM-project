================================================================================
          CAREERBRIDGE DATABASE SETUP & PHPMYADMIN GUIDE
================================================================================

This guide will walk you through setting up the MySQL Database for the CareerBridge
project using XAMPP and phpMyAdmin. You will find step-by-step instructions
followed by the SQL commands to run.

--------------------------------------------------------------------------------
STEP 1: Start XAMPP Control Panel
--------------------------------------------------------------------------------
1. Open the "XAMPP Control Panel" on your computer.
2. Click the "Start" button next to "Apache".
3. Click the "Start" button next to "MySQL".
4. Make sure both turn green. If you face port conflicts, make sure Skype or other
   web servers are closed.

--------------------------------------------------------------------------------
STEP 2: Open phpMyAdmin
--------------------------------------------------------------------------------
1. Open your web browser (Chrome, Edge, Firefox, etc.).
2. In the URL bar, type:
   http://localhost/phpmyadmin/
   and press Enter.
3. This opens the MySQL database administration interface (phpMyAdmin).

--------------------------------------------------------------------------------
STEP 3: Create the Database
--------------------------------------------------------------------------------
1. In phpMyAdmin, click on "New" (or "Databases" tab on the top menu).
2. Look for the input field under "Create database".
3. Type the Database Name: career_bridge
4. Change the Collation dropdown (next to database name) to: utf8mb4_general_ci
5. Click the "Create" button.

--------------------------------------------------------------------------------
STEP 4: Run the SQL Script to Create Tables
--------------------------------------------------------------------------------
1. Click on the newly created database "career_bridge" in the left sidebar.
2. At the top menu bar of the page, click on the "SQL" tab.
3. Empty any text inside the big text area, and copy-paste the SQL script below.
4. Click the "Go" button (bottom right) to execute the commands.

================================================================================
                            SQL SCRIPT
================================================================================

-- 1. Create Users Table
CREATE TABLE IF NOT EXISTS `users` (
  `id` INT AUTO_INCREMENT PRIMARY KEY,
  `username` VARCHAR(50) NOT NULL UNIQUE,
  `email` VARCHAR(100) NOT NULL UNIQUE,
  `password` VARCHAR(255) NOT NULL,
  `role` ENUM('employer', 'seeker', 'recruiter', 'admin') NOT NULL,
  `profile_pic` VARCHAR(255) DEFAULT NULL,

  -- Employer Profile specific columns
  `company_name` VARCHAR(100) DEFAULT NULL,
  `company_industry` VARCHAR(100) DEFAULT NULL,
  `company_description` TEXT DEFAULT NULL,
  `company_website` VARCHAR(255) DEFAULT NULL,
  `company_logo` VARCHAR(255) DEFAULT NULL,

  -- Job Seeker Profile specific columns
  `resume_path` VARCHAR(255) DEFAULT NULL,
  `headline` VARCHAR(255) DEFAULT NULL,

  `created_at` TIMESTAMP DEFAULT CURRENT_TIMESTAMP
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- 2. Create Jobs Table (Employer job posts)
CREATE TABLE IF NOT EXISTS `jobs` (
  `id` INT AUTO_INCREMENT PRIMARY KEY,
  `employer_id` INT NOT NULL,
  `title` VARCHAR(100) NOT NULL,
  `category` VARCHAR(100) NOT NULL,
  `description` TEXT NOT NULL,
  `requirements` TEXT NOT NULL,
  `salary_range` VARCHAR(100) NOT NULL,
  `location` VARCHAR(100) NOT NULL,
  `job_type` VARCHAR(50) NOT NULL,
  `deadline` DATE NOT NULL,
  `status` ENUM('active', 'closed') NOT NULL DEFAULT 'active',
  `created_at` TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  FOREIGN KEY (`employer_id`) REFERENCES `users` (`id`) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- 3. Create Applications Table (Seekers apply for jobs)
CREATE TABLE IF NOT EXISTS `applications` (
  `id` INT AUTO_INCREMENT PRIMARY KEY,
  `job_id` INT NOT NULL,
  `seeker_id` INT NOT NULL,
  `cover_letter` TEXT NOT NULL,
  `resume_path` VARCHAR(255) NOT NULL,
  `status` ENUM('Submitted', 'Reviewed', 'Shortlisted', 'Rejected') NOT NULL DEFAULT 'Submitted',
  `created_at` TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  FOREIGN KEY (`job_id`) REFERENCES `jobs` (`id`) ON DELETE CASCADE,
  FOREIGN KEY (`seeker_id`) REFERENCES `users` (`id`) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- 4. Create Saved Jobs Table (For the seeker's bookmarking feature)
CREATE TABLE IF NOT EXISTS `saved_jobs` (
  `id` INT AUTO_INCREMENT PRIMARY KEY,
  `seeker_id` INT NOT NULL,
  `job_id` INT NOT NULL,
  `created_at` TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  UNIQUE KEY `unique_save` (`seeker_id`, `job_id`),
  FOREIGN KEY (`seeker_id`) REFERENCES `users` (`id`) ON DELETE CASCADE,
  FOREIGN KEY (`job_id`) REFERENCES `jobs` (`id`) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

--------------------------------------------------------------------------------
TIPS
--------------------------------------------------------------------------------
- The database name is "career_bridge"
- In your PHP code (db_connection.php), use:
  - Database host: localhost
  - Database username: root
  - Database password: (leave empty)
  - Database name: career_bridge

- Passwords are hashed with PHP's password_hash() (bcrypt) before being stored,
  and checked with password_verify() at login. The `password` column will always
  contain a hash starting with $2y$ or $2b$, never the plain-text password.
